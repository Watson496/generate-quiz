# generate-quiz

日本語の競技クイズ（早押しクイズ）の問題を作成するAgent Skillを収めたリポジトリです。

## 利用方法

| 利用環境 | 設定・利用手順 | インストール・登録するファイル |
|---|---|---|
| Agent Skills対応のAI agent | [skills/README.md](skills/README.md) | `skills/generate-quiz/` |

## 作問の既定動作

デフォルトでは、以下の要素を満たすような形で作問を行います。

- 題材を「subject」「place」「time」「type」の4つの軸からなるファセット分類に基づいて、直近の問題と類似の題材が選ばれにくくする形にweightを調整した重み付き乱択で選ぶ
- 問題文の形式は、ストレート型の「〜は何でしょう？（SC型）」「〜を何というでしょう？（OV型）」の構文に制約する
- 文字数は80文字付近を最頻値とした許容度曲線に基づいて確率的に採否を決める
- 異なる述語・関係は別々の命題に分け、作文前の予定命題と完成稿から抽出した実現命題を双方向に照合し、Web検索で裏取りを行う
- 作文の前後で各述語の主体・目的語・場所・部位・条件などの項構造を照合し、係り先や指示対象の変化があれば改稿する
- 問題文の対応箇所と出典記述を逐語引用し、複合命題の全検証要素と資料の確認状態を示す
- 連体修飾節の被修飾名詞を保って命題を復元し、一部分の事実と、その内容で対象全体を特徴づける中核性・代表性を分けて検証する
- 一回的な個別事実、反復・継続、作風・傾向、評価・知名度などの事実の種類と代表性を別々に判定し、問題文の述語を資料が支える強さに合わせる
- 修飾形式と作用域を一致させ、独立した前フリが読み上げ時に対象の事実を累加的に述べるものとして伝わるかを確認する
- 難易度は、分野の初学者には基礎的で、分野外の一般層には通常知られていない水準とする
- 題材を代表する情報を問題文の終端に置き、説明から名称を容易に作れる問題や、別の対象を当てるだけで答えられる問題を棄却する
- 作文前と完成後に各手掛かり単位の中核性・準一意性・非重複性を検査し、分類側と手掛かり側の両方向から対抗候補を探す
- 出力には別解・正誤判定基準・一意性の評価・留保・参考文献を添える

## 出力形式

出力は、問題・解答に加えて、別解、正誤判定基準、題材選択（4軸の階層パス）、初学者と一般層を分けた難易度評価、問題成立性の確認、裏取り情報、参考文献を含みます。裏取り情報では、「問題文の表現・命題・出典記述の対応」で、各実現命題に問題文の対応箇所と出典の逐語引用を添え、全手掛かり単位を引用した情報選択の確認、表記、正誤判定、一意性、留保を示します。異なる述語・関係は別々の実現命題として示し、主体の切替えや場所句の係り先などを誤りやすい複雑な命題には、必要な項構造も添えます。連体修飾節が直接述べる局所命題と、核名詞句全体による特徴づけ命題の差が実質的な場合は、両者を区別します。事実の種類・述語の強さ・代表性が論点になる場合は、出典が支える事実、最終述語、採用理由の対応を示します。前フリの叙述的提示性は、警告・境界・改稿があったものだけ具体的に説明します。weightや抽選の過程、不採用になった候補、予定命題台帳は表示しません。

出力順は次のとおりです。

```text
問題：……
解答：……
補足
別解
正誤判定基準
題材選択（subject／place／time／type）
難易度評価（当該分野の初学者／分野外の一般層／判定）
問題成立性の確認
裏取り情報
- 検証状況
- 問題文の表現・命題・出典記述の対応
- 情報選択の確認
- 解答・別解・表記の検証
- 正誤判定に関する検証
- 解答の一意性
- 留保
参考文献
```

## 作問結果の確認

出力では、難易度評価が初学者と分野外の一般層に分かれ、問題成立性の確認が実際の解答と手掛かりに即した説明になっていることを確認します。裏取り情報には、問題文の表現・実現命題・出典記述の対応、全手掛かり単位の比較範囲・対抗候補・中核性・準一意性・固有の寄与が具体的に示されている必要があります。

文字数の指定では、「60文字以内」で本文（「問題：」を除く）が60文字以内に収まること、代表情報・一意性・自然さを壊して無理に短縮しないことを確認します。条件内で成立しなければ、条件外の問題を黙って出さないことも見ます。「100文字前後」では厳密な一致より日本語の自然さと問題成立性を優先します。主題を指定した場合は、それを候補集合の制限として扱い、他の軸と具体的な題材を選ぶことを確認します。

過去問を渡した場合は、末尾を最新として、ファセット・顕著な対象・使用済みの命題を推定し、次の選択へ反映することを確認します。曖昧な下位分類を作らず、過去問と同一・含意・意味的に近い命題を再利用しないことも見ます。

問題文と正誤判定では、次を重点的に確認します。

- 一般層にも有名な題材を、周辺的な情報で人工的に難しくしていない
- 終端に、解答対象と同じ抽象度・射程の代表説明がある
- 前フリと落としの各手掛かり単位が、中核性・準一意性・非重複性を満たす
- 弱い手掛かりを字数のために残さず、削除後に文字数の許容度を再評価する
- 説明から名称を容易に作れる問題や、別の対象を当てるだけの問題を採用していない
- 格、時制・相、継起・因果・対立、集合と構成員の関係が正しく、読み上げ順に無理なく理解できる
- 完成稿から作問意図を参照せずに実現命題を抽出し、予定命題との不一致や複数の自然な読みがあれば問題文を改稿する
- 分類・使用場面・機能・目的などの異なる述語・関係を別命題に分け、完成文全体を一命題として扱っていない
- 作文の前後で主体、目的語、場所句の係り先、部位の所属、指示対象、条件などの作用域が一致し、不一致があれば問題文を改稿する
- 検証要素は一つの述語・関係の内部条件に用い、複合命題の全検証要素を確認し、資料の直接確認・間接確認・未確認と、直接記載・演繹・解釈を区別する
- 連体修飾節の検証で、巡礼路を巡礼、著作を一節などの関連対象に読み替えていない
- 一部分の存在や知名度だけで対象全体の代表性を認めず、対象全体を扱う概説などで位置づけを確認する。部分関係を明示した改稿後も全品質基準を再検査する
- 一回的な個別業績と反復・継続する活動を区別し、回数性と代表性を混同していない。傾向や評価を採用理由にする場合は、それを直接支える資料と対応する述語を用いる
- 場所・時代・分野などの前置表現が、名詞を限定するのか事態全体を限定するのかに合った修飾形式になっている
- 独立前フリが累加的な叙述として明確に聞こえなければ再構成・移動・差し替え・削除する。落としにはこの検査を適用せず、文字数や読点だけで合否を決めない
- 出典を逐語引用し、非連続箇所を合成せず、省略・引用者補足を明示する
- 外国語資料は原文を示し、対応する公認・刊行訳を優先する。適切な既存訳がなければAIによる訳であることを明示する
- 所在は印刷ページを主とし、必要に応じてPDF通算ページを補助併記する。無年資料は`n.d.`とする
- 問題全体の検証状況は最も弱い必須要素に合わせる。単純命題には引用と所在を示し、引用内容の言い換えだけの検討を付けない
- 自然な正答範囲を先に定めて問題成立性を確認し、問題文と回答断片を連結して正答にしていない

## 構成

```text
README.md                  共通の作問仕様・出力形式・開発案内
skills/
  README.md                Agent Skillsのインストール・利用手順
  generate-quiz/           インストールするスキル一式
    SKILL.md
    references/
    scripts/
tests/                     開発用の回帰テスト
```

利用手順のREADMEは設定ファイル一式の外に置いています。`skills/generate-quiz/` をコピーしてインストールする際に、READMEは含まれません。

## 開発

工程制御は `skills/generate-quiz/SKILL.md` で管理します。題材選定・履歴は `selection_and_history_spec.md`、問題文生成は `quiz_generation_spec.md`、裏取り・正誤判定は `verification_and_judging_spec.md` に定義します。

Agent Skillsに同梱するPythonスクリプトの回帰テストは、リポジトリのルートで実行します。

```bash
python3 tests/test_cli_contracts.py
```

`tests/` は開発用で、各環境へインストール・登録するファイルには含めません。
