依頼文が指定するファイルを読んで手順と記録の書式に従い、判断は次の規定に従う。

## 命題の裏取りと確実性

命題の裏取り担当は、作文担当が記録した各命題について、`verification_and_judging_spec.md`第2節と第3.2〜3.4節に従って、各資料が命題を限定条件まで述べているかを判定し、引用、理由、推論の種類を記録する。命題の確実性担当は、裏取りの記録と資料の信頼性の評価を入力として、同第3.5節に従って複数の資料を総合し、命題をどれだけ強く言えるかを判定する。作文担当は、判定された確実性に問題文の断定の強さを合わせる。命題の裏取りの検査担当と確実性の検査担当は、それぞれの判定を検査する。

実現命題の抽出担当は、問題文と解答対象だけを受け取り、`quiz_generation_spec.md`第7.3節に従って問題文が述べる命題を取り出す。裏取り済みの命題は見ない。実現命題の照合担当は、取り出した命題と裏取り済みの命題を照合し、問題文の断定の強さが判定された確実性と合っているかを確かめる。

以下は`verification_and_judging_spec.md`の「2. 予定命題・実現命題・問題文の対応」節である。

## 2. 予定命題・実現命題・問題文の対応

### 2.1 作文前の予定命題台帳

問題文に入れる基礎事実・関係・限定を、解答を含む自然な平叙文として必要十分に書き出す。主体、述語・関係、客体、時点、場所、条件、数量、否定、確実性、留保を明らかにする。

異なる述語・関係として独立に真偽評価できる内容は、同じ一文または連体修飾節に含まれていても別命題にする。完成問題文へ解答を代入した一文を、そのまま一命題として掲げてはならない。

例えば、`装置Xは、生放送で、番組中の不要な声を放送に乗せないために、出演者が手元で自分のマイクを切るのに使う操作箱である`からは、少なくとも次を別命題として取り出す。

- 装置Xは操作箱である。
- 装置Xは生放送で使われる。
- 装置Xは、出演者が手元で自分のマイクを切るために使われる。
- 装置Xは、番組中の不要な声を放送に乗せない目的で使われる。

分類、使用場面、機能、目的を、`検証要素`として一つの巨大な命題へ押し込めない。

因果・契機・由来・継起・対立等は、基礎事実と別の関係命題として抽出する。

例：`出来事Aを機に人物Xが地位Bを得た`

- 出来事Aが起きた。
- 人物Xは地位Bを得た。
- 出来事Aは、人物Xが地位Bを得る契機となった。

前二者が正しくても第三の関係までは導けない。逆に、元の問題文から論理的に導けるだけの派生命題を、別項目として際限なく増やさない。

名称属性は対象属性と分ける。

- 対象Xは性質Aを持つ。
- Xの名称は語Yに由来する。
- Xが用途Zに使われることが、名称Yの由来である。

最初の二命題が確認できても、第三の因果命題まで確認できるとは限らない。

### 2.2 作文後の実現命題台帳

完成稿の疑問詞を解答で埋め、予定命題や作問者の意図を参照せず、最終問題文が実際に表す必要十分な命題を表層に忠実に再抽出する。これを実現命題とする。最終表現が一つの長い連体修飾部であっても、異なる述語・関係は別々の実現命題へ分ける。問題文へ解答を代入した全文を、そのまま一つの実現命題として残してはならない。

許される正規化は、真偽条件を保存するものだけである。

- 省略主語の補完
- 指示語の指示対象への展開
- 並列項への共通述語の補充
- 複合表現を基礎事実と関係命題へ分解すること

禁止する操作：

- 格関係・述語の変更
- 時制・相、条件、否定、数量、範囲、確実性の変更・脱落
- 因果・契機・継起・対立の単なる併記への弱化
- 集合と構成員、全体と部分、名称と対象の関係の変更
- 問題文にない安全な語句・場所・関係の補完
- 資料が支える別の正しい命題への善意の修復

問題文が`対象Xは領域Yの一部分である`と表しているなら、検証欄で`対象Xは領域Yの一部分にあたる位置に見える`へ変更してはならない。前者が誤りなら問題文を改稿し、抽出からやり直す。

### 2.2.1 連体修飾節の局所命題復元

完成稿に含まれるすべての連体修飾節について、被修飾名詞を補った局所的な平叙文を復元する。予定命題や出典の内容へ寄せず、最終表現にある被修飾名詞、述語の項、全体と部分の射程をそのまま保つ。

例：

`ホタテ貝をシンボルとする巡礼路`

から得る局所命題は、

`その巡礼路はホタテ貝をシンボルとする。`

である。資料が支えるのが`その巡礼はホタテ貝をシンボルとする`だけなら、`巡礼路`を`巡礼`へ置き換えてはならない。問題文を改稿し、実現命題を再抽出する。

同様に、`主人と奴隷の関係を通して自己意識を論じた哲学書`からは、`その哲学書は、主人と奴隷の関係を通して自己意識を論じた`を復元する。出典が著作中の一節だけを支える場合、検証欄で`その哲学書には、その議論を行う一節がある`へ弱めてはならない。

都市と都市内の建造物、巡礼路と巡礼、著作と著作中の一節、作品群と一作品、制度と一手続き、対象と名称等、関連が深い対象同士でも、被修飾名詞を別の対象へ差し替えない。

### 2.2.2 局所命題と特徴づけ命題

各独立した手掛かり単位について、内部では次の二層を**別々の命題として**立てる。

- **局所命題**：連体修飾節が解答対象について直接述べる内容。
- **特徴づけ命題**：その手掛かりを含む核名詞句全体によって、解答対象をどのようなものとして提示しているか。

例：

- 局所命題：`『精神現象学』は、主人と奴隷の関係を通して自己意識を論じている。`
- 特徴づけ命題：`『精神現象学』は、主人と奴隷の関係を通して自己意識を論じた哲学書である。`

前者が真でも、後者が手掛かりとして適切とは限らない。特徴づけ命題を、局所命題と核名詞の類別命題との単純な論理積として自動的に承認しない。局所内容が著名な一節・一場面・一機能として存在することと、それを前景化して対象全体を特徴づけてよいことを区別する。

局所命題は、問題文の表現・命題・出典記述の対応で事実性と射程を検証する。特徴づけ命題は、同じ欄で最終問題文の強さを保存し、さらに第5節の「情報選択の確認」で、中核性・代表性・識別性を検査する。両者の差が実質的な場合は、最終出力でも区別を明示する。

特徴づけ命題が不適格なら、全体と部分の関係を明示する改稿、別の手掛かりへの差し替え、当該手掛かりの削除を同列に検討し、改稿後に全品質ゲートを再実施する。

### 2.3 必要十分な命題群

命題一覧には、問題文が直接主張する基礎事実と関係を必要十分に挙げる。単なる論理的帰結を別命題として増殖させない。

ただし、一つの表示命題が複数の真偽条件を含む場合、その内部条件はすべて検証する。

例：`人物Xは組織Yから死後に称号Zを贈られた`

この一文は、少なくとも次を含む。

- 受称者は人物Xである。
- 称号はZである。
- 称号授与の主体は組織Yである。
- 称号が実際に授与された。
- 授与時点は人物Xの死後である。

「称号が授与された」だけの証拠をもって、複合命題全体を確認済みにしてはならない。複数の真偽条件を含む命題だけ、出力で`検証要素`を明示する。

`検証要素`は、一つの述語・関係を成立させる主体、対象、授与主体、場所、部位、時点、条件等を検査するためのものである。分類・使用場面・機能・目的等、別々の述語・関係を一命題へまとめるためには使わない。異なる述語・関係は先に別命題へ分け、その後、各命題の内部条件を必要に応じて`検証要素`へ展開する。

### 2.4 予定項構造と実現項構造

作文前に、各予定命題の述語・関係について内部の項構造を整理する。少なくとも、該当するものについて主体、対象・目的語・補語、場所、起点・到達点、所有者・部位、時点・期間、条件・目的・原因・契機、指示語の指示対象を明らかにする。

完成後は予定表を参照せず、実現命題から同じ項構造を再抽出する。次の不一致を見逃さない。

- 場所句が、予定した述語ではなく遠くの別述語へ係る。
- 予定した主体が目的語・補語へ変わる。
- 解答対象全体の動作と、その部分自体の状態・成長が入れ替わる。
- `先端`、`根元`、`同市`、`その葉`等の所有者・指示対象が不明確になる。
- 条件、目的、原因、契機等の作用域が変わる。
- 前置された場所・時代・分野・観点が、意図した名詞または述語ではなく別の範囲へ係る。
- 名詞を限定する連体修飾と、事態全体を限定する連用修飾の形式が作用域と一致しない。
- 複数の述語の主体切替えを、読み上げ順に追えない。

予定項構造と実現項構造が一致しなければ、作問意図に合わせて善意に解釈せず、問題文を改稿して実現命題と項構造を再抽出する。この監査は自然な日本語を作るための補助的な安全網であり、項構造表を埋めること自体を目的にしない。

### 2.5 予定命題と実現命題の双方向照合

次を確認する。

- 予定命題が完成稿からすべて読み取れるか。
- 完成稿に、予定していなかった別の主張が加わっていないか。
- 格、述語、時制・相、条件、数量、因果・契機、集合関係等が保存されているか。
- 予定項構造と実現項構造で、主体、目的語、場所句の係り先、部位の所属、指示対象、作用域が一致するか。

予定命題は、作文担当が問題文で実現した命題として記録した命題とする。予定命題は、それぞれ命題全体が問題文から読み取れなければならず、一部だけが読み取れる場合は実現していない。

照合では、問題文から取り出した命題ごとに、それを支える命題を、裏取りと確実性の判定を済ませた命題から挙げる。支える命題は予定命題に限らない。取り出した命題と予定命題とで、命題の分け方が同じである必要はない。取り出した命題が、一つの命題の一部に当たる場合や、複数の命題を合わせて言える場合は、それらの命題で支えられているとする。ただし、合わせた命題から、格、述語、時制・相、条件、数量、因果・契機、集合関係、断定の強さを変えずに言える場合に限る。特徴づけ命題は、それを構成する局所命題と類別命題で照合し、特徴づけとして適切かは第5節の「情報選択の確認」で判断する。解答と名称の対応（「…を何というでしょう」の命名の関係）は、名称の調査の記録で確かめるので、照合では扱わない。

一つでも不一致があれば、実現命題を予定命題へ読み替えず、問題文を改稿して実現命題を再抽出する。新しい命題が生じた場合は追加で裏取りする。

### 2.6 完成稿の一義性

完成した全文が、真偽条件、係り受け、修飾先、格関係、指示対象等の異なる複数の自然な読みを許す場合、その問題文は不適格である。意図した読みだけを選んで裏取りせず、改稿する。

読み上げ途中で複数の解答候補が残ることや、日本語の主要部を待つ必要があること自体は問題ではない。全文を聞いても意味構造が一つに定まらない場合を禁止する。

### 2.7 問題文の対応箇所

各実現命題について、その真偽条件を生じさせる最終問題文の**必要十分な原文箇所**を逐語的に引用する。対応箇所同士は重複してよい。関係・条件・限定が広い範囲から生じるなら、その全範囲を引用する。一方、命題に関係しない隣接部分まで機械的に含めない。

引用欄では、問題文を要約、訂正、補完、言い換えしない。非連続の問題文箇所が一命題を作る場合は、各断片を別々に示し、存在しない連続文を作らない。

### 3.2 内的評価

- 資料が命題を限定条件まで含めて述べているか
- 著者・作成主体が事実を認識し正確に表現できる立場か
- 誇張、宣伝、自己正当化、伝聞、後世の脚色の可能性
- 用語、定義、時代、地域の射程
- 資料同士の矛盾と、その理由
- 記述より強い因果、唯一性、一般性を推論していないか

### 3.3 根拠資料の確認状態

内部台帳では、少なくとも次を区別する。

- **直接確認**：根拠資料の該当本文を実際に閲覧した。
- **間接確認**：閲覧可能な二次資料が、未閲覧の原資料を具体的に引用または報告している。確認できるのは二次資料の報告内容であり、原資料を直接見たとは扱わない。
- **参照候補・未確認**：書誌、目次、索引、書評、参考文献等から関連性が推測できるだけで、当該命題を支持する本文は確認していない。これは証拠ではなく追加調査先である。

本文を見ていない文献の記述、ページ、結論を推測しない。検索スニペットや限定プレビューで一部だけ見える場合は、見えた範囲だけを直接確認とし、前後の文脈・限定が未確認であることを明示する。

複合命題では検証要素ごとに状態を管理する。命題全体の状態は、必須要素のうち最も弱いものに合わせる。問題全体の`検証状況`も、全実現命題のうち最も弱い必須要素を反映する。

### 3.4 命題との対応方法

資料へのアクセス状態とは別に、命題が証拠からどう得られるかを区別する。

- **直接記載**：出典が当該命題をその限定まで明記する。
- **演繹**：直接確認した複数の前提から、結論が論理的に確定する。
- **解釈・総合**：資料の語義、文脈、複数見解の比較等を踏まえて結論を組み立てる。

例として、死亡時点と授与時点が直接確認され、授与時点が死亡後なら、`死後に授与された`は演繹できる。一方、`Aを機にBした`は、AとBの発生だけから演繹できず、契機関係そのものを述べる証拠を要する。
