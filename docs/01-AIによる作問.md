# AIによる作問

クイズの問題をAIに作らせるとき、単に「クイズの問題を作ってください」と頼むだけでは、十分な品質の問題ができないことが多いです。ここには、そもそも「どういう問題を作りたいのか」「問題に求める品質はどのようなものか」が明確でない、という問題があります。

競技クイズの業界では、クイズの問題がどうあるべきかについて、「正しい情報に基づくべき」とか「問題から解答が一意に定まるべき」とかについての緩やかな共通認識はあります。ですが、細部についてはかなり多様性があり、標準が定まっているわけではありません。なので、AIに問題を作らせる際には、自分が作りたい問題がどのようなものなのかを、具体的に規定して指示する必要があります。

generate-quizでは、以下のような項目について詳細に検討しています：

- [題材の配分](02-題材の配分.md)
- [問う知識の選定](03-問う知識の選定.md)
- [手掛かりの設計](04-手掛かりの設計.md)
- [問題の成立性](05-問題の成立性.md)
- [問題文の構成](06-問題文の構成.md)
- [問題文の表現](07-問題文の表現.md)
- [問題文の長さ](08-問題文の長さ.md)
- [判断の根拠](09-判断の根拠.md)
- [解答と正誤判定](10-解答と正誤判定.md)

なお、ここではあまり一般的ではない独自基準を採用しているものもあります。これはあくまで私（WaTTson）が私好みの問題を作るための規定の仕方の例であって、これを広く業界標準にすべきと主張しているものではないことを断っておきます。

これらの規定を実際のツールへ落とし込んだ形は[Agent Skillsでの実装](11-Agent_Skillsでの実装.md)と[GPTsでの実装](12-GPTsでの実装.md)に、本文中で参照した文献は[参考文献](13-参考文献.md)にまとめてあります。
