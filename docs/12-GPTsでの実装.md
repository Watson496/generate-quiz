# GPTsでの実装

同じ規定を、ChatGPTのGPTsとしても実装しました。作問方針は共通で、実行環境の制約に応じて落とし込み方が異なります。

構成としては、InstructionsとKnowledgeに分け、Instructionsに工程制御を、Knowledgeに仕様と分類カタログを置いています。Instructionsには編集画面の上限として8,000文字の制約がありますが、内容を詰め込みすぎると指示に従わなくなるため、設計目標は6,500文字以内としています。分類カタログは、subjectを最上位コードごとに9分割し、place・time・typeは各1ファイルとしています。

また、スクリプトを同梱できないため、重みの正規化、履歴補正、乱択、文字数の計測と許容度判定にはCode InterpreterのPythonを使います。Agent Skills版でスクリプトが担っていた計算を、その場で書かせる形になります。Pythonの実行に失敗した場合に作問を中止する点は、Agent Skills版と同じです。
