# 問題文の長さ

競技クイズでは、問題群の特徴を「短文」「長文」という言葉で示すことが多いです。これについて、徳永 (2021b)『競技クイズの問題文の文字数分布』では、問題集ごとの文字数分布がざっくり対数正規分布に近い分布を示すことを調べました。問題集についての「短文」「長文」という評価は、問題集ごとにこの分布の分散がある程度小さく、その平均文字数が短い、もしくは長いことを呼んだものと考えられます。

generate-quizでは、80±20文字程度の文字数の問題文を作るのを標準としています。徳永 (2021b)で機械的にとった平均は約57.3文字でしたが、abc/EQIDENの作問ガイドラインが60文字以下を基準にしていることを考えると、この平均は若干短文寄りになっていると思われます。一方、長文の問題文はざっくり100文字以上と言われることが多いです。generate-quizではその中間程度を標準とすることにし、既定の最頻値を80文字、広がりをおおむね20文字としました。

もっともこれは、機械的に「60〜100文字」のような範囲で単に与える形はとりません。80文字が最大となるような対数正規型の許容度曲線を考え、これに基づいて採否を決める形にしています。

文字数条件によって不採用となった場合は、同じ裏取り済みの命題だけを使い、言い回しを変えて作り直します。文字数を合わせるための情報の追加や削除はしません。正確性、一意性、自然さ、代表性、非自明性は、文字数より優先されます。
