# 問題文の構成

競技クイズの問題文には、様々な種類の構文が存在します。徳永 (2023b)『競技クイズの問題文の統語構造に基づく分類』では、abc/EQIDENの問題群を分析して、2つの構文類型を取り出しました：

- SC型：「Nは」＋疑問詞を含む名詞句＋「〜でしょう？」。1,016問
- OV型：「Nを」＋疑問詞を含む名詞句＋「〜というでしょう？」。444問
- SV型：そのいずれでもない動詞文・形容詞文を元にしたもの。40問

## 採用する構文

generate-quizでは、これらの構文の中でSC型とOV型の2種類、かついわゆる「ストレート型」の問題文に構文を制約することにしました。こうしておくとAIに構文の選択を委ねる範囲が狭くなるので、出力が安定すると考えられます。SC型とOV型では問題文の後半に核となる名詞句が存在し、先行する連体修飾節がこの名詞句にかかる形式となります。

パラレルのような「ですが」構文も採用しないものとしました。ただし、連体修飾部の内部で時間・理由・対立などの従属関係を作ることは妨げません。例えば、「伝承ではAとされるが、資料上はBとみられる制度」の「が」は一つの連体修飾部の中の対立であって、禁じている「Aですが、Bは何でしょう？」とは別のものです。

## 前フリと落とし

競技クイズの問題文は、一般に「前フリ」と「落とし」によって構成されると言われています。前フリには、対象の成立史、機能、受容、代表的な内容など、対象についての事実を置きます。前フリであっても、手掛かりに求める中核性・代表性や準一意性は変わりません。

落としは、答える対象が何であるかを端的に説明する、核となる名詞句と、それに最も近い連体修飾部です。自然な上位分類と、対象を特徴づけるために必要な種差を置きます。対象そのものを説明しない辺縁的な特徴を落としに置いたり、「映画」「制度」のような広い分類だけで終えたりはしません。

前フリは、核となる名詞句に複数の連体修飾部が前置されているとき、落としより前で、解答対象について別の事実を叙述的に加える部分です。核となる名詞句の前にある情報をすべて前フリと呼ぶわけではありません。落としに当たる連体修飾部しかなければ、前フリはありません。

OV型では、核となる名詞句より後に、答える名称の範囲を限定する修飾部を置くことがあります。これは後限定として、核となる名詞句ではなく「いう」「呼ぶ」などの命名を表す動詞にかかります。例えば、

> 同じ長さの2本の線分でも、両端につけた矢羽が内向きか外向きかによって異なる長さに見える錯視を、1889年にこの図形を考案したドイツの社会学者・心理学者の名から何錯視というでしょう？

という問題文では、
「同じ長さの2本の線分でも、両端につけた矢羽が内向きか外向きかによって異なる長さに見える錯視」が落としであり、「1889年にこの図形を考案したドイツの社会学者・心理学者の名から」が後限定です。

後限定は、原則として、それがなければ正答となる別名が落としの語句から容易に復元でき、解答の露出によって問題が成立しなくなる場合に限って置きます。この例では、現象を表す英語別名の「arrowhead illusion」は、「矢羽」と「錯視」が表す内容をそのまま名称化したものです。そこで後限定により、答える名称を考案者の名に由来する呼称へ限定し、露出した別名を正答範囲から除きます。後限定がなくても解答の露出が起きない問題では、名称の範囲を狭めるためだけに後限定を置きません。

## 複数の情報の接続

複数の情報を盛り込んだ問題文を作る場合、それぞれを連体修飾節にして同じ核となる名詞句へ係らせるのが標準的な構文となります。「京都に生まれた、作品Aを代表作とする、賞Bを受賞した作家」のような形です。

連用中止は、並列・継起・理由・対立などの意味関係が実際に成立する場合だけ使います。例えば、「小規模な会報として創刊され、のちに全国誌へ発展した雑誌」には、創刊から発展への継起があります。一方、「京都に生まれ、作品Aを代表作とし、賞Bを受賞した作家」は、異質な属性を接着しているだけで並列が成立していません。逆に、意味上のつながりがあり連用中止を使う方が適切な場合に、命題を独立した修飾節へ分断して、継起や因果を隠すことも避けます。

## 手掛かりの順序

競技クイズでは、解答へ到達しにくい手掛かりを前に、到達しやすい手掛かりを後ろに置くのが通例です。generate-quizでもこれを強い指針とします。各位置までに示された文脈を前提として、想定プレイヤー層がその事実を知っている可能性、知っていた場合に解答へ直接到達できる程度、既出の手掛かりと組み合わせたときに候補を限定できる程度を比べます。事実単体の知名度だけでは順序を決めません。

順序の判断も、教育上の位置づけ、一般向け媒体での扱われ方、専門分野での代表的な結び付きなど、Web検索で得た資料中の情報に基づいて行います。検索件数・順位や印象だけで精密な順序を作りません。

ただし、日本語としての自然さ、時系列、因果関係、係り受け、終端の落としを壊してまで機械的に並べ替えることはしません。

順序の指針とほかの条件が衝突する場合は、順序だけを動かす前に、使う手掛かりや構文を選び直します。前半の手掛かりだけで、対象固有の非自明な対応を知っている人が正答できることは、それだけでは不適格としません。
