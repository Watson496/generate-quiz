# Agent Skillsでの実装

ここまでの規定を、Agent Skills形式のスキルとして実装しました。

## ファイルの構成

規定は、工程制御と3つの仕様に分けています：

- SKILL.md：作問の工程を制御する
- selection_and_history_spec.md：題材選定、重み、履歴
- quiz_generation_spec.md：問題文の生成
- verification_and_judging_spec.md：裏取りと正誤判定

分類データは1ファイルが最大約260KBあるため、全文を読み込まず、必要なノードのブロックだけを取り出す形にしています。

## 計算とWeb検索

重みの正規化、履歴による補正、乱択、文字数の計測と許容度による採否判定は、Pythonスクリプトに担当させています。AIに乱択や計数を行わせても、指定した分布や数値になる保証がないためです。Pythonの実行に失敗した場合は、作問を中止します。

裏取りについても、Web検索を必須の工程とし、検索手段が使えない場合は作問を中止します。

## 出力

出力には、問題と解答のほかに、補足、別解、正誤判定基準、題材選択の階層パス、難易度評価、問題成立性の確認、裏取り情報、参考文献を含めています。一方、内部の重み、抽選の過程、不採用になった候補、命題台帳は出力しません。

## 担保される範囲

この実装で担保されるのは、計算に落とせる部分だけです。具体的には次のような点になります：

- 分類ノードの選択が、指定した重みに従った分布になること
- 履歴による補正が、定めた式のとおり計算されること
- 問題文の文字数が、指定した制約を満たすこと
- 各問について裏取りのためのWeb検索が行われること

逆に、次の点は担保されません。分類ノードの重みの推定と、階層のどこで細分化を止めるかの判断はAIが行っているので、一貫性は保証されません。subjectに用いたUDC主標数の非直交性により、題材空間の切り分けには歪みが残ります。裏取りはWeb検索で到達できる資料の範囲に制約されます。固有度の高い対象の再出現を抑える尺度に、実証的な根拠はありません。そして、時点に依存する情報は、作問時点で正しくても後に正しくなくなります。
