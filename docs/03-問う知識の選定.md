# 問う知識の選定

題材の領域が決まったら、その領域から具体的な解答候補を集めます。領域内で探索を繰り返し、別の切り口で検索しても有力な候補がほとんど増えなくなった時点を、探索の飽和とみなします。集めた候補には、題材の配分で用いたものと同じ観点から相対的な重みを与えて抽選します。

候補を選んだだけでは、何を知識として問うかは決まりません。同じ対象についても、対象そのものを同定させる問題と、その名称や呼称を提示させる問題とでは、問う対応が異なります。対象について確認できる事実を並べてから問題文を作るのではなく、対象についてのどの非自明な対応を知っているかを問うのかを先に定めます。

## 答えさせる内容

問題の解答として答えさせる内容には、次の制約を設けます：

- 1問につき一つの対象または名称を答えさせる
- 解答は原則として名詞で表せるものとする
- 集合の一部を示して残りを答えさせる列挙問題は作らない
- 年・数値・数量そのものを答えさせる問題は作らない

対象そのものを同定させる場合と、特定の名称・呼称を提示させる場合は区別します。後者では、どの言語や形式の名称を求めるのかが問う知識の一部になります。適切な正答範囲を定められない候補は採用しません。

## 難易度

競技クイズの問題群では、難易度もあまりばらつきが出ないように配慮されるのが通例です。そして難易度をどう定めるかは、結局どの層の解答者を基準に置くかの問題になります。

generate-quizでは、徳永 (2023c)『クイズの作問過程を言語化してみる』で述べた基準を既定としています。その分野に特段深く触れてきた経験のない人は知らないが、学ぼうと思い立てば1〜2年以内に知りうるもの、という水準です。この基準は、元をたどれば「大学1〜2年生程度の専門知識」という考え方から生まれたものですが、それでは主題が学術分野に限られてしまうので、芸術・スポーツ・芸能・生活文化などにも適用できる形へ一般化してあります。

この基準は次の二つの条件から成り、両方を満たす必要があります：

- その分野を継続的に学び始めて1〜2年以内の人には、中核的な情報から正答を期待できる
- その分野を特に学んでいない一般的な日本語話者には、通常は正答を期待しにくい

後者の判定には、学校教育だけでなく、日常生活、公的制度、報道、大衆文化、著名人や代表作との結び付きによる知名度も考慮します。

難易度も、入門書、概論、シラバス、公式の初心者向け教材など、Web検索で得た資料中の情報に基づいて評価します。分野学習者と一般層のそれぞれについて、資料中の情報と、そこから正答可能性を判断する推論を対応させます。内部知識、印象、検索件数・順位、資料が見つからないことだけを根拠にはしません。両方の参照集団について十分な根拠を得られない候補は採用しません。

## 候補の採否

抽選した候補について、問う知識と難易度の条件を満たし、適切な手掛かりを構成できるかを確認します。一時的なニュース、珍しいだけの逸話、特殊な数値や一つの適用例しか問える内容がない候補は採用しません。条件を満たさない場合は題材領域の重みを下げず、その候補だけを除いて抽選し直します。
