# 問題の成立性

クイズの問題は、想定した解答が問題文中の各事実を満たすだけでは成立しません。問題文全文と正誤判定規則を合わせたときに、何を答えればよいかが実用上十分に定まり、その答えへ至るために対象についての非自明な知識が必要となることを求めます。

## 解答の一意性

問題文全文を読んだ時点で、採用する正誤判定規則の下で解答が実用上十分に定まる必要があります。想定した解答から手掛かりを確認するだけでなく、手掛かりから逆向きに対抗候補を探します。その際には、上位概念、下位概念、同名の対象、別名、定義の差、時点の差を検査します。

数学的に可能な候補を際限なく列挙するわけではありません。想定するプレイヤー層が、実際の問題傾向と問題文から自然に比較する範囲で、有力な候補が残るかを判断します。その範囲で複数の対象が同程度に残る問題は採用しません。

対象そのものを問う場合、同じ対象を正当に指す別の名称を排除して一意性を作ることはしません。特定の言語、形式、呼称を問う場合は、要求する名称の範囲を問題文で明示します。

## 解答の露出

対象を知らなくても、問題文中の語句から解答を復元できる問題は採用しません。解答そのものや正答となる別名・略称に加え、容易な翻訳、同義置換、略称展開によって解答に還元できる表現も避けます。読み上げたときに解答が同音で現れる場合や、手掛かりが解答名称の識別的な部分をほぼ供給する場合も同様です。

語源や外国語での意味は、解答との対応が非自明であれば手掛かりに使えます。例えば、エクレアの名がフランス語で「稲妻」を意味する語に由来するという情報は、語義を知るだけでは日本語の解答をそのまま復元できません。一方、簡単な英単語の直訳を示し、その訳語を答えさせるような問題は、対象についての知識を問うものになりません。

この判定は、正誤判定基準で回答に必要とされる、固有性の高い部分について行います。固有性の低い分類語が問題文中に現れていても、それとは別に回答に必要な固有性の高い部分が露出していなければ、直ちに不成立とはしません。

特定の呼称を求めることが問題文に明示されている場合は、その条件を適用した後の正答範囲について解答の露出を判定します。条件がなければ正答となる別名が問題文中の語句から容易に復元できても、その別名が明示された条件によって正答範囲から除かれ、実際に要求する名称の識別的な部分が露出していなければ、問題は成立します。明示された条件を適用しても露出した名称が正答に含まれる場合は採用しません。
