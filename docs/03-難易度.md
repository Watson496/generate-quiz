# 難易度

競技クイズの問題群では、難易度もあまりばらつきが出ないように配慮されるのが通例です。そして難易度をどう定めるかは、結局どの層の解答者を基準に置くかの問題になります。

generate-quizでは、徳永 (2023c)『クイズの作問過程を言語化してみる』で述べた基準を既定としています。その分野に特段深く触れてきた経験のない人は知らないが、学ぼうと思い立てば1〜2年以内に知りうるもの、という水準です。この基準は、元をたどれば「大学1〜2年生程度の専門知識」という考え方から生まれたものですが、それでは主題が学術分野に限られてしまうので、芸術・スポーツ・芸能・生活文化などにも適用できる形へ一般化してあります。

この基準は次の二つの条件から成り、両方を満たす必要があります：

- その分野を継続的に学び始めて1〜2年以内の人には、中核的な情報から正答を期待できる
- その分野を特に学んでいない一般的な日本語話者には、通常は正答を期待しにくい

後者の判定には、学校教育だけでなく、日常生活、公的制度、報道、大衆文化、著名人や代表作との結び付きによる知名度も考慮します。

また、題材となる情報そのものの裏取りとは別に、難易度の評価に対しても文献に基づく立証を求めます。ただし、難易度の評価には、事実の裏取りほどには厳密な立証を求めません。入門書、概論、シラバス、公式の初心者向け教材などがあれば参照しますが、資料がなければ、必要な前提知識、専門性、概説での扱われ方から総合的に判断する形になります。
