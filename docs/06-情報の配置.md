# 情報の配置

競技クイズの問題文は、一般に「前フリ」と「落とし」によって構成されると言われています。

このうち「落とし」の要素としては、その対象そのものが何なのかを端的に説明するものを置きます。対象そのものの説明ではない辺縁的な特徴の説明を落としに置くことはしませんし、「映画」「制度」のような広い分類だけで終えることもしません。

「前フリ」には、対象の成立史、機能、受容、代表的な内容など、対象の特徴の説明として幅広い内容が含まれえます。ただし、前フリだからといって、中核性や準一意性の要件を緩めることはしません。

## 前フリの聞こえ方

独立した前フリとして置く連体修飾節は、通常の速度と自然な間で読んだとき、解答対象について一つの事実を累加的に述べる叙述として聞こえることを求めます。後続する名詞句と一体化し、その候補群を絞り込む限定条件のように聞こえる場合は採用しません。

例えば「『ソロモンの指環』を著した、オーストリアの動物行動学者」の前半は限定条件のように聞こえますが、「『ソロモンの指環——動物行動学入門』を著した、オーストリアの動物行動学者」だと叙述として聞こえます。事実としての性格は両者でほとんど変わらないので、これは表現の水準の問題です。

なお、この条件は落としには課しません。落としの役割は、上位分類と種差によって対象を同定することだからです。

## 情報の順序

競技クイズでは、知名度の低い情報を前に、高い情報を後ろに置くのが通例です。generate-quizもこれを強い指針としますが、日本語としての自然さと競合する場合には、自然さの方を優先します。時系列、因果、係り受け、終端の落としを壊してまで機械的に並べ替えることはしません。実際に衝突が起きた場合は、順序だけを動かす前に、使う情報や構文を選び直します。また、前半の手掛かりだけで、対象固有の非自明な対応を知っている人が正答できることをもって、機械的にNGとはしません。

問題文は、読み上げられる順に意味を構成できるものにします。長い部分を聞いた後で、それまでの全体を大きく解釈し直させる構成は避けます。例えば、「観測で、気流の変化により像が揺らぐ……天体の指標」は、最初の段階では何の観測なのかが明に分からず、最後まで聞いて初めて天体観測の話だと分かります。「地上からの天体観測で、気流の変化により像が揺らぐ……指標」なら、前から理解できます。

## 手掛かりの数

手掛かりの数は固定せず、指定された問題文長にふさわしい情報密度にします。字数を満たすためだけの限定や雰囲気付けを入れることはしません。

## 解答の露出

問題文は、対象を知らなくても語句から解答を復元できる形にならないようにします。問題文中に解答そのもの、あるいは正答となる別名や略称を含めないのはもちろん、容易な翻訳、同義置換、略称展開で解答に還元できる表現も使いません。読み上げたときに解答が同音で露出する表現も同様です。

語源や外国語での意味は、解答との対応が非自明であれば手掛かりに使えます。例えば、エクレアの名がフランス語で「稲妻」を意味する語に由来することは、多くの日本語話者にとって非自明です。一方、簡単な英単語の直訳を示すだけでは、問題として成立しません。

この判定は、問題の解答における固有性の高い部分、つまり正誤判定基準で「〜が出れば○」と扱われるような要素について行います。固有性の低い部分のみが問題文中に出てくること自体は、別に固有性の高い部分があってそれが問題文に露出していないのであれば、問題ありません。

## 一意性の確認

問題文全文を読んだ時点で、採用する正誤判定規則の下で解答が一意に定まる必要があります。想定した解答が各手掛かりを満たすことの確認だけでは足りず、手掛かりから逆向きに対抗候補を探し、上位概念、下位概念、同名の対象、別名、定義の差、時点の差を検査します。

SC型で対象そのものを問う場合、同一対象を正当に指す別の名称を排除して一意性を作ることはしません。OV型や名称を限定するSC型では、要求する言語・形式・呼称の範囲を問題文で明示します。
