# 入力形式

各問をUTF-8のMarkdownファイルにする。ファイル名先頭の番号順に処理し、`README.md` と隠しファイルは無視する。

`# 第1問` の後に `問題：……` と `解答：……` を1行ずつ置き、次のレベル2見出しを各1回、この順で置く。

1. 補足
2. 別解
3. 正誤判定基準
4. 題材選択
5. 難易度評価
6. 問題成立性の確認
7. 裏取り情報

各欄では、より深い見出し、段落、強調、箇条書き、引用、インラインコード、URLなど、Pandocが扱える通常のMarkdownを使用できる。追加のレベル1・レベル2見出しは配置が曖昧になるため受理しない。

レベル1見出しの番号、ファイル名先頭の番号、全ファイルの連番は一致させる。構造エラーが出た場合はAgentが内容を確認し、推測で処理を続けない。

`### 参考文献` の本文では、一つの文献記述とその直後のURLを一組とし、文献間を空行で区切る。自動変換は記述全体をBibエントリーへ保持し、各問末尾で `\fullcite` により出力する。
