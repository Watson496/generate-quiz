# クイズ問題集LaTeX

番号付きのクイズMarkdown群から、自己完結したLaTeXプロジェクトを作る。Markdownを正本とし、ユーザーが編集を求めない限り、本文と全付帯項目を省略・言い換えしない。

## 手順

1. 入力ディレクトリと、それとは別の出力ディレクトリを確認する。出力先が空でない場合は、ユーザーが更新を明示的に許可していない限り停止する。
2. 入力構造の検証・診断時は[入力形式](references/input-format.md)を読む。
3. `scripts/build_quiz_book.py INPUT OUTPUT` を実行する。`--update` は、空でない出力先の更新が明示的に許可された場合だけ付ける。スクリプトは同梱テンプレートを複製し、全問を検証し、PandocでMarkdownを変換し、LaTeX本文とBibデータを作る。`--no-compile` がなければ `latexmk` でPDFまで作る。
4. 構造検証に失敗したら、差異の意味を確認する。必須見出しの欠落・改名・重複・順序変更を黙って読み替えない。
5. ログとPDFを確認する。特に一覧表、実ページ番号、相互リンク、参考文献、URLの改行、日本語、最初と最後の解説を見る。

## 出力上の不変条件

- 表紙、問題群の作成日、使用ツール、使用モデルの値は `main.tex` で変更可能にする。
- 問題一覧の前に、`generate-quiz`が生成する問題と解説の性質を説明するページを置く。この説明では、次を省略しない。
  - SC型・OV型の一文へ限定し、独立した前置き節、重文、「ですが」構文を使わず、情報を核名詞句へ収束させる構文制約
  - 各手掛かりへ個別に求める中核性・準一意性・非重複性
  - 部分についての事実と、対象全体を代表する特徴との区別
  - 容易な語形成や別対象の同定だけで答えられる問題を除く、問題としての非自明性
  - 回答が対象を十分に指定するかに基づく正誤判定と、別解・部分回答の区別
  - 問題文の表現、表層から読み取れる命題、出典の逐語引用の対応
  - 各手掛かりについての現実的な対抗候補との比較
  - 直接確認・間接確認・未確認の区別と、最も弱い必須要素を反映する検証状況
  - 当該分野の初学者と分野外の一般層を分ける難易度評価
  - 80字付近を最頻域とし、固定的な上下限にはしない文字数分布
  - subject・place・time・typeの分類と、分類・命題・固有対象の再出現抑制
- 説明中で用いる`ファセット`、subject・place・time・type、SC型・OV型等、解説へ出現し得る独自用語は、競技クイズの一般的なプレイヤーが解説を読めるよう初出で定義する。ファセットは4軸の役割、UDCとオントロジーに基づく分類の援用、階層表示、`限定なし`の意味を、SC型・OV型は基礎となる平叙文、問う対象、正答範囲の違いを説明する。
- `No.／問題／解答／解説ページ` の表を実質的な目次にする。
- 実ページ番号を印刷し、同じ文字列にPDF内の相互リンクを設定する。
- 各解説は改ページして始め、問題番号・問題・解答を再掲する。
- Markdownの全セクションを収録し、参考文献は対応する問の末尾に置く。
- 参考文献は `biblatex` とBiberで管理する。入力の自由記述を失わないことを優先し、自動変換では各記述を一つのBibエントリーとして保持する。
- モノクロ印刷で簡潔に読める組版にし、リンクだけを青色にする。
- `contents/` は文書上の役割を表すLaTeXソース群である。自動変換後に直接編集せず、修正はMarkdown正本またはテンプレートへ戻す。

## 依存コマンド

Pandoc 3以降、LuaLaTeX、`latexmk`、Biberを使う。不足している依存物を無断でインストールせず、コマンド名を報告して停止する。
